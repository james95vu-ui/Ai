# Возрождение ЧР — Android-проект (этап подготовки APK)

В проекте находится Android-оболочка на Java WebView, которая запускает текущий HTML/CSS/JS-прототип из `app/src/main/assets`.

## Что включено
- Название приложения: **Возрождение ЧР**
- Package ID: `com.vozrozhdenie.chr`
- Иконка: горы Кавказа и восходящее солнце (адаптивная Android-иконка)
- Вертикальная ориентация
- Встроенные локальные файлы игры
- Сохранение демо-прогресса в WebView localStorage

## Как собрать APK на компьютере
1. Установите Android Studio (актуальную стабильную версию) и Android SDK Platform 35.
2. Распакуйте архив.
3. В Android Studio выберите **Open** и укажите папку `vozrozhdenie-chr-android`.
4. Дождитесь Gradle Sync и установки необходимых компонентов.
5. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
7. Перенесите APK на Android-телефон и разрешите установку из выбранного источника.

## Текущие ограничения
Это пока локальный прототип в Android-оболочке. В нём нет многопользовательской синхронизации, серверной экономики, Supabase Auth или защиты игровых операций. Для работы WebView-интерфейса не требуется Telegram; Telegram Web Apps SDK активируется только при открытии внутри Telegram.

## Важное для Google Play
Перед публикацией нужно будет:
- подключить backend и серверную проверку личности;
- реализовать политику конфиденциальности и заполнить Data safety;
- подготовить release signing key и подписанную сборку AAB;
- проверить требования актуальной версии Google Play и SDK target;
- проверить права на все изображения, шрифты и контент.

Не добавляйте секретный Supabase `service_role` ключ в приложение. В APK любой клиентский код можно извлечь.
